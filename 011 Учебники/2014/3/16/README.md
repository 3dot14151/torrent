###  Подробнее

Приведены методы расчета конструктивных элементов линий электропередачи на механическую прочность, определения расчетных нагрузок на промежуточные, промежуточные угловые, анкерные, анкерные угловые и концевые опоры линий электропередачи.Изложены основы проектирования железобетонных, металлических и деревянных опор.
