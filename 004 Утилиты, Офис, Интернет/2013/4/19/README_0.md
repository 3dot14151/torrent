Web Dumper автоматически скачивает документы HTML вместе со встроенными в них изображениями, звуками, роликами и т.п., одновременно сканируя их на предмет присутствующих в них ссылок на другие документы. К тому же Web Dumper поддерживает последовательное скачивание. Действительно, можно получать содержимое путем заключения последовательности чисел в скобки прямо в адресе.
