###  Подробнее

KoolMoves, обновление приложения для работы и создания web-анимации, с использованием инструментов для работы с Flash и анимированными (-gif-) файлами. Программа для создания web-анимации KoolMoves, может применять разнообразные спец-эффекты к тексту, импортировать векторную графику, добавить аудио, в формате (-wav-), осуществить градиентную заливку созданной кривой, присвоить различные действия кнопкам и изображениям. Благодаря особой функциональности и простоте, с KoolMoves может работать даже новичок, не имеющий опыта работы с Flash-анимацией. Пользователь программы для создания web-анимации сможет создать не обыкновенные flash-ролики, которые можно будет применить в роли баннеров, при создании мультимедийного слайд-шоу, создании системы навигации по сайту и т. д.Язык интерфейса: Английский
