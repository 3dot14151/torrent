###  Подробнее

7z SFX Builder предлагает расширенные возможности в работе с самым популярным стандартом сжатия. Формат 7Z является одним из самых эффективных способов упаковки файлов. Данная утилита позволяет создавать архивы с каталогами и файлами, помещая информацию в самораспаковывающийся модуль. Для извлечения таких данных пользователю не нужно использовать дополнительные программы-архиваторы. 7z SFX Builder содержит множество параметров упаковки файлов - от выбора алгоритма сжатия и настройки ярлыков до указания сопроводительных надписей и возможности использования пароля. В процессе работы самораспаковывающегося модуля можно скрывать графический интерфейс, делая процесс извлечения файлов невидимым. Конфигурацию создаваемого архива можно тестировать непосредственно в самой программе.Язык интерфейса: Multi/Rus (by loginvovchyk)
