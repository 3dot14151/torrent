###  Подробнее

Intel® Processor Diagnostic Tool - это средство диагностики проводит проверку торговых марок, проверяет процессор рабочую частоту процессора, тестирует процессор характеристики, и не нагрузочное тестирование процессор.

Это средство диагностики может быть настроена для работы в одном или двух режимах: в режиме тестирования или режиме проверки. Кроме того, его можно настроить для включения или отключения отдельных конфигураций по умолчанию используется в этом режиме работы.Язык интерфейса: Английский
