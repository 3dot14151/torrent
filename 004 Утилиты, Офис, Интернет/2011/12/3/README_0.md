Средство управления многопользовательской активацией (VAMT)
Средство VAMT позволяет управлять системами, активированными с помощью ключа MAK (ключа многократной активации). Средство VAMT позволяет собирать данные о клиентах, лицензированных с помощью ключа MAK, в том числе сведения о ключах продуктов и текущем состоянии лицензии, и сохранять эти данные в файле CIL (в файле списка сведений о компьютере). Для этих клиентов от средства VAMT поступает команда на активацию непосредственно с помощью центра Майкрософт (независимая активация MAK), или для активации могут быть собраны и отправлены данные в пакете. Способ создания пакета называется прокси-активацией, которую может выполнять узел VAMT, собирающий данные. Данные могут быть экспортированы также на съемный носитель, а пакет может быть отправлен в корпорацию Майкрософт с другого узла VAMT. Средство VAMT отправляет также на серверы Microsoft® Activation в сети (серверы активации продуктов Майкрософт) запросы на определение числа активаций, возможных с помощью (   Читать дальше...   )Язык интерфейса: Русская и английская версии
