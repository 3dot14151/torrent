###  Подробнее

Компьютерная программа Cross+A предназначена для решения кроссвордов, сканвордов, криптарифмов, судоку и японских кроссвордов (черно-белых и многоцветных нонограмм), а также для поиска анаграмм, словосочетаний, цепочек слов и метаграмм. Программа использует базу данных, содержащую более 97000 слов с описаниями. Базу данных можно редактировать: добавлять слова, удалять, изменять описания (доступна проверка правописания). Пользователь может импортировать (вставлять) в базу программы слова из своих текстовых файлов и создавать собственные базы слов.
Cross+A включает в себя графический редактор для создания японских кроссвордов, а также генераторы для автоматического создания логических головоломок.Название программы: Cross+AЯзык интерфейса: Rus
