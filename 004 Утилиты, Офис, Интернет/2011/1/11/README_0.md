###  Подробнее

iCare Data Recovery - программа для восстановления удаленных и отформатированных файлов с жестких дисков, sd карт, карт памяти и USB Flash накопителей. Программа поможет восстановить файлы с нечитааемого раздела диска, если поврежден загрузочный сектор или после вирусной атаки.

В программу входят 4 мастера восстановления:
• Partition Recovery для восстановления удаленных разделов
• Deleted File Recovery для восстановления удаленных файлов, файлов из поврежденных разделов или поврежденного загрузочного сектора и т.д.
• Deep Scan Recovery для сканирования и поиска как существующих, так и удаленных файлов, которые можно восстановить
• Format Recovery для восстановления файлов с офтормтированных жестких дисков, внешних дисков, sd карт, USB Flash накопителей.Язык интерфейса: английский + русификатор (от kuchkan)

###  Подробнее

Утилита Recovery Toolbox for RAR предназначена для восстановления информации из поврежденных архивов формата RAR. Благодаря ней можно полностью избежать или хотя бы минимизировать потери сжатой информации. Работает утилита следующим образом: сначала она осуществляет полное сканирование и анализ поврежденного архива, извлекает из него всю информацию, какую только можно, далее полученный список файлов и папок выводится на экран. Пользователь может просматривать этот список и выбирать для сохранения только те объекты, которые ему нужны. При этом некоторые файлы программа может восстановить в некорректном виде или не восстановить вообще. Это связано со степенью поражения поврежденного архива. Извлеченные файлы и папки сохраняются в указанном пользователем месте, после чего они доступны для использования. Немаловажным является тот факт, что в результате работы исходный архив остается неизмененным и никаким образом не модифицируется, данные из него только считываются программой.Язык интерфейса: Retail-Eng, Portable-Rus
