###  Подробнее

Handy Backup - программа для резервного копирования, восстановления и синхронизации данных. Автоматически по расписанию создает архивную копию файлов, папок, баз данных, образ диска. Резервирует данные на HDD, USB, DVD, CD, Blu-Ray, HD DVD, LAN, FTP/SFTP сервер. Поддерживает шифрование, ZIP-сжатие.
Автоматически находит и копирует Мои документы, письма Outlook, Windows mail, The Bat, файлы ICQ, базы 1С, MySQL, MS SQL и др.
Вышла новая версия Handy Backup 6.9 и Handy Backup Server 6.9 с новой функциональностью. Handy Backup 6.8 добавляет в контекстное меню Windows Explorer новую опцию «Бэкап с Handy Backup», с помощью которой вы можете создать новую задачу резервного копирования для выделенных данных. Данный тип интеграции работает с файлами и папками. В следующих же версиях программы Новософт планирует создать тот же механизм для;Язык интерфейса: multilanguage (русский присутствует)
