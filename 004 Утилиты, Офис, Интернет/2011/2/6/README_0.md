###  Подробнее

Если системный блок спрятан от глаз или просто отсутствует — HddLed Indicator, небольшая программа, которая отобразит на мониторе индикатор активности жесткого диска. HddLed Indicator поможет решить проблему контроля за работой винчестера и, заодно, логических дисков и съёмных флэш накопителей. Программа может работать сразу с несколькими дисками, совсем несильно нагружает систему. Маленький индикатор на мониторе будет мигать так же, как и светодиодный индикатор на жестком диске компьютера. Очень удобная замена светодиодного индикатора жесткого диска. Индикаторы можно разместить на любом участке монитора, а также изменить цвет отображения. Есть функция назначения индикатора Scrol Lock клавиатуры.

Features:
•	Monitor multiple hard drives.
•	Monitor multiple logical discs.
•	All-in-one mode — single indicator for all drives.
•	Use keyboard ScrollLock led to indicate activity.
•	Use system tray to indicate activity.
•	Separate read and write operations.
