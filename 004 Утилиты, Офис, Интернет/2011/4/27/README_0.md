Архиватор WinArchiver - считается одним из самых мощных, надёжных и многофункциональных утилит среди множества современных архиваторов, предназначенных для работы в среде операционной системы Microsoft Windows. WinArchiver - это комплексное программное обеспечение, обладающее широчайшими возможностями создания, управления и распаковки различных архивов. Утилите WinArchiver подвластны практически все известные форматы архивации: ZIP (WinZip), 7z, RAR (WinRar), ISO (CD/DVD Image), WIM (Windows Imaging), DMG (Apple Disc Image), CAB (Microsoft Cabinet), GZIP и т.д.
