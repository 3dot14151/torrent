###  Подробнее

HDD Raw Copy Tool – утилита для полного, по-секторного копирования содержимого жестких дисков компьютера с возможностью создания сжатого образа данных, поддержкой всех типов носителей S-ATA (SATA), IDE (E-IDE), SCSI, SAS, USB, FIREWIRE, в т.ч. SSD-накопителей, а также флеш-карт. На копируемых дисках может быть любая файловая система с любым количеством разделов (в т.ч. скрытых), копируется также и MBR, загрузочные сектора, «плохие» сектора пропускаются. Данные можно переносить напрямую на целевой диск (при миграции к примеру) или сохранять в файл (сжатый .imgc или не сжатый .raw) для дальнейшего использования.Язык интерфейса: Английский
