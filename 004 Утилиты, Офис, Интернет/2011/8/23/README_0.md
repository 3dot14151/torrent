###  Подробнее

Inquiry - программа позволяет быстро и просто сохранять веб-страницы целиком или некоторые их фрагменты. Открытые вами страницы сохраняются всего одним кликом. Программа имеет встроенный HTML-редактор, возможность поиска внутри сохраненных страниц и многое другое. Предназначена для работы под различными системами Windows и полностью интегрировано в Microsoft Internet Explorer. Помимо интеграции с IE, Inquiry интегрируется в Firefox, а также имеет самостоятельное решение, позволяющее использовать его и в качестве браузера, и в качестве программы для сохранения страниц. В последних версиях добавлено подтверждение, когда страница сохраняется или, если страница с таким адресом уже есть в папке, диалог свойства папки, возможность изменения начальной страницы в браузере программы, возможность показывать последнюю открытую страницу при запуске. Inquiry имеет русифицированный интерфейс и русскую справку для помощи в освоении этой программы.Язык интерфейса: RUS
