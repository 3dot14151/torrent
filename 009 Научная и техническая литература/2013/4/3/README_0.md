Описывается история языков семейства Basic, применение Visual Basic к реализации линейных, разветвляющихся и циклических алгоритмов, работа с подпрограммами и файлами, мультимедийные возможности языка при оформлении созданных приложений, написание простых игр. В конце книги даны справочник по языку и решения избранных задач.Формат: PDF
