Программа определяет все оборудование в системе, извлекает ассоциируемые драйверы с жесткого диска и копирует их по местоположению по вашему выбору. Более того, программа Driver Magician имеет встроенную базу данных последних драйверов с возможностью получать обновления в Интернете. Программа экономит время при поиске правильных драйверов, которые улучшат производительность вашего оборудования.
