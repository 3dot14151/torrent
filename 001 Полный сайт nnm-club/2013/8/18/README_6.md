Но, поскольку полный набор из нужных редакций Windows 7 на нескольких языках занимает довольно много места, то с целью сэкономить дисковое пространство было принято решение использовать штатные средства (Windows Automated Installation Kit for Windows 7 and Windows Server 2008 R2) и создать универсальные (содержащие различные редакции Windows 7) образы с интегированными в них последней версией Internet Explorer, языковыми пакетами и обновлениями.
    После установки вы будете иметь оригинальную версию Windows 7 (изменено только фоновое изображение "по умолчанию", смотрим скриншоты)Язык интерфейса: английский, русский, украинский
