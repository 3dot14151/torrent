В Linux Mint 15 было обновлено настольное окружения XFCE, а также добавлены новые приложения для управления прикладным софтом и новые драйверы. Linux Mint 15 Olivia базируется на последней версии операционной системы Ubuntu 13.04 и разработчики планируют поддерживать эту версию до января 2014 года.

Здесь же появились два новых инструмента управления программами: Источники программ и Менеджер драйверов. В новой версии ОС была реализована поддержка свежих драйверов для Nvidia, ATI и Broadcom.
