###  Подробнее

Итальянские разработчики представили очередной релиз CAINE (Computer Aided INvestigative Environment) – специализированного Ubuntu-based GNU/Linux Live-дистрибутива с комплектом open source утилит для forensic-анализа и тестирования на несанкционированное проникновение компьютерных систем.

Основные изменения в релизе CAINE 4.0: ядро 3.2.0-38; LibreOffice 4.0.1; Sqliteman; NirSoft Launcher с образом FTK и инструментами sysinternals;  добавлены Remote Filesystem Mounter, sdparm, netdiscover, утилиты RBFstab (активируемая в момент начальной загрузки или подключения устройства утилита, подставляющая в /etc/fstab значение read-only, что обеспечивает безопасное монтирование устройств для проведения forensic-экспертизы) и mounter (приложение для монтирования дисков, управление которым осуществляется из системного лотка);   исправлены ошибки в netcat и GHex.
