###  Подробнее

KolibriOS (англ. KolibriOS — КолибриОС) — операционная система для PC, полностью написанная на ассемблере fasm, распространяемая на условиях GPL. Создана на основе MenuetOS. Является альтернативной операционной системой, так как она использует собственные стандарты и не основана на POSIX. Система рассчитана на использование ассемблера для написания приложений, но есть и программы, написанные на языках высокого уровня (Си, C++, C--, Free Pascal, Forth). На данный момент большинство разработчиков живут на территории стран СНГ.
 Особенности KolibriOS

    Множество вариантов загрузки, в том числе с NTFS-раздела. Также возможна загрузка прямо из Microsoft Windows (при этом Windows, конечно, завершается), не требующая установки системы.
    GUI на основе VESA. Возможность увеличения частоты монитора за счет уменьшения разрешения.
    Среда разработки: редактор, макро-ассемблер (fasm) для сборки ядра и приложений.
    Поддержка TCP/IP-стека и некоторых сетевых карт.
    Основной дистрибутив помещается на одной 3,5" дискете.
