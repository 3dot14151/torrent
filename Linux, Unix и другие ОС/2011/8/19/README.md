Вышла очередная версия оригинальной, простой и бесплатной программы Sweet Home 3D, которой  пользуются для проектирования интерьера. Эта великолепная бесплатная программа разработана на языке программирования Java и, кроме всего прочего, имеет открытый исходный код. При работе с данной программой можно использовать 3D-модели, которые в большом количестве представлены на официальном сайте и доступны пользователям для бесплатной загрузки.

Sweet Home 3D позволит Вам предварительно просмотреть получившийся интерьер в 2D режиме (вид сверху), а также визуализировать конечный вариант расстановки мебели в 3D режиме.
