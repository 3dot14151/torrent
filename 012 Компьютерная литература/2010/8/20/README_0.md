образом, чем это было сделано когда либо ранее, высококвалифицированные авторы

примерами кода из реальных программ атаки и исправлений, вносимых хакерами в
популярные приложения. Читателям наглядно демонстрируется, как выявлять неизвестные
уязвимые места в программном обеспечении и как можно их использовать для
взлома компьютеров. Книга предназначена для профессионалов в области программного
