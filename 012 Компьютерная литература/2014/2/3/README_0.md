###  Подробнее

Книга посвящена одной из самых интересных тем - работе с текстом в Photoshop. Материал разделен на две части. В первой приводятся основные сведения о работе с соответствующими функциями программы: ввод текста, манипуляция с ним, использование контуров и фигур, эффектов слоев, а также такой важный вопрос, как выбор шрифта.
