###  Подробнее

HDR Camera+ – это программа, которая поможет создать красивые фотографии в стиле HDR на Android смартфоне, используя встроенную камеру. Для достижения такого эффекта, приложение создает три снимка с разной экспозицией и объединяет их в один, сохраняя детализацию в темных и светлых участках фотографии. В настройках можно изменить некоторые параметры съемки для достижения желаемого результата.
